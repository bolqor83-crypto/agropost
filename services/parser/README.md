# Парсер цен (этап 2.5)

Отдельный Python-сервис: FastAPI + Telethon + httpx + selectolax.
Запускается по cron, пишет результаты в ту же базу (Neon).

## Правила (не нарушать)

- Собираем **только обезличенные данные**: цены, названия, характеристики, ссылки.
- **Без телефонов и ФИО** (152-ФЗ).
- **Агросервер**: HTTP + HTML-парсинг (selectolax), без авторизации.
- **Telegram**: Telethon (MTProto), **отдельный аккаунт** (не основной),
  лимит 1–2 запроса/сек, паузы, не более 500 каналов на аккаунт.
- **Авито**: отложено. Только полуавтомат — открыть страницу вручную.
- Каждый адаптер имеет лимиты и статус («активен», «ограничен», «выключен»).
  Если источник блокирует — адаптер отключается, приложение не падает.
- Результат — строка «Рынок: 85–95 ₽/кг» в карточке позиции, обновление раз в день.
- Уведомление — только по правилу пользователя (например, «конкурент ниже на 10%»).

## Запуск (когда наступит этап 2.5)

```bash
pip install -r requirements.txt
uvicorn app.main:app --port 8000
```
