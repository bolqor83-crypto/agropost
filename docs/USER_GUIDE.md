# АгроПост — руководство пользователя

Расширенное руководство по всем экранам и правилам приложения.
Короткая версия (быстрый старт из 7 шагов) — в [README.md](../README.md).
Приложение одно-пользовательское: вы — владелец-посредник, продаёте семена
трав и грецкий орех от своего имени, поставщик для покупателя невидим
(white-label).

Как читать: разделы идут по нижней навигации — «Пульт», «Разместить»,
«Сделки», «Инбокс» — и по «Ещё» для остальных разделов. Каждый экран
открывается с ленты: жмите карточку, чтобы раскрыть детали.

## Пульт — главный экран

Домашний экран «тихого помощника». Не дашборд с графиками — только то,
что нужно для решения «что сделать сегодня»:

- **«Разместить товар»** — главная кнопка, ведёт в мастер размещения.
- **Карточки аналитики**: маржа за неделю, активные сделки, новые лиды
  сегодня — клик ведёт в «Аналитику».
- **Позиции** — первые 4 карточки с остатком, ценой за кг и мешком;
  «Все (N)» открывает полный каталог.
- **Последние размещения** — лента: куда и когда размещали, авто через
  бота или полуавтомат, города ротации.
- **«Что сделать?»** — 1–3 карточки-действия с приоритетами (лиды без
  ответа, сделки ждут оплаты, каналы «остыли» после cooldown). Когда
  действий нет — «Сейчас всё под контролем». Если AI недоступен,
  подсказка собирается по правилам, без AI.
- **Шапка**: бейдж новых сообщений (Инбокс) и счётчик активных сделок.

При первом входе с пустыми реквизитами сверху появляется мягкий баннер
«Добро пожаловать! Начните с заполнения реквизитов» — кнопка ведёт
в «Ещё» → «Реквизиты», «Позже» убирает баннер до лучших времён.

## Разместить — главный поток, 4 шага

Мастер публикации объявления — сердце приложения.

1. **Позиция**: карточки остатков (цена продажи, мешок, минимальная
   партия). Нет позиций — подсказка с кнопкой в «Позиции и остатки».
2. **Каналы**: умный подбор под товар (тег → свой регион → «здесь давно
   не размещали» → активность → охват). Виджет «Ротация по региону»
   подсказывает город дня; каналы в cooldown помечены «⏳ N дн» и стоят
   внизу (выбрать можно, но это спам-риск). «Показать все каналы» —
   полный каталог.
3. **Текст**: сервер собирает черновик по шаблону площадки (white-label,
   без поставщика). «Сгенерировать с AI» — улучшенная версия, её можно
   править, автосохранение в черновик. Для своих каналов с ботом —
   кнопка «Опубликовать через бота» (одним нажатием); для чужих площадок —
   «Скопировать» + deep link на точку входа (бот-приёмщик, админ, форма),
   после публикации отметка «Размещено».
4. **Итог**: сводка «размещено в N каналов», лента на Пульте обновится.

Совет про гео-ротацию в шаге «Каналы» показывается один раз — как
начнёте пользоваться ротацией, он больше не вернётся.

## Сделки — от лида до закрытия

Список сделок с фильтрами (Все / В работе / Завершены / Отменены),
поиском по номеру/покупателю/товару и кнопкой «+ Новая сделка».

Карточка сделки — всё в одном окне:

- **Таймлайн статусов**: Заявка → Ожидает оплаты → Оплачено → Отгружено →
  Доставлено → Закрыто. Переходы — кнопками («К оплате», «Оплачено»,
  «Отгрузить», «Доставлено», «Закрыть»).
- **Экономика**: объём, цена, выручка, **маржа после налога** (зелёная —
  хорошо, красная — сделка в минус). Закупочная цена помечена «скрыт от
  покупателя» и в документы не попадает.
- **Документы**: кнопки «Счёт / Договор / ТН / УПД» — PDF генерируется
  и скачивается сразу; все версии сохраняются в карточке.
- **Рекламации**: «+ Создать» — описание, до 12 фото (JPEG/PNG/WebP,
  до 10 МБ), можно переадресовать поставщику — покупатель его не увидит.
- **Отгрузка**: реквизиты отправления (ТК, номер накладной) —
  «Отгрузить» после оплаты.

Правило денег — везде на виду: **отправка только после полной оплаты**;
предоплату не берём, доставку оплачивает покупатель (в маржу она не
входит). При создании первой сделки мастер напомнит об этом правилом.

Создать сделку можно: из «Сделок» (кнопка «+»), из карточки лида
в «Инбоксе» (контакт подставится сам) или из карточки позиции.

## Инбокс — покупатели из Telegram-бота

Сообщения, которые покупатели пишут боту, попадают сюда. Карточка лида:
имя, @username или телефон, регион, интерес («Люцерна 1 класс, 20 т»),
история переписки.

- **«Черновик AI»** — собранный ответ с ценой и условиями: правьте
  и отправляйте одной кнопкой.
- **«Сделка»** — превращает лида в сделку с предзаполненным покупателем.
- Лиды без активности не «протухают» сами — статус меняете вы
  (Новый → В работе → Сделка/Отказ).

Уведомление о новом сообщении приходит в ваш Telegram, бейдж «Новые: N»
виден на Пульте.

## Каналы — каталог площадок

Каталог всех площадок размещения: Telegram-каналы и чаты, Авито,
Агросервер, MAX, Юла и другие. Фильтры по типу и тегам (семена, орех,
опт, общий), поиск.

Карточка канала хранит то, что нужно для подачи:

- **Способ подачи**: бот-приёмщик / админ-контакт / форма сайта /
  личный кабинет. В мастере «Разместить» кнопка ведёт в правильную
  точку входа («Открыть @Taganrog_Predlozhka_bot», «Написать @admn_013»).
- **Регион и город** — для гео-ротации (см. ниже).
- **Лимит подач** (например, «2 раза в день») и статус проверки:
  «проверен» или жёлтый бейдж «требует проверки».
- **Зеркала** TG↔MAX — контент дублируется, публикуемся в одно.

Аккаунты (мультиаккаунты по площадкам) — рядом в «Ещё» → «Аккаунты»:
платформа, статус, лимит размещений в день (по умолчанию 20).
Счётчик «использовано сегодня» растёт при отметке «Размещено» и
сбрасывается на следующий день.

## Аналитика — простые факты

Три вкладки — «Сводка», «Каналы», «Позиции» — и периоды
(неделя / месяц / всё время):

- **Сводка**: выручка и маржа по закрытым сделкам, средний чек, лиды,
  конверсия, топ культур по марже, топ каналов по лидам.
- **Каналы**: подписчики и средний охват (разные показатели!),
  размещения/выходы, лиды → сделки, средняя маржа, последняя публикация.
- **Позиции**: сделки, выручка, маржа, средняя цена (взвешенная по
  объёму), дни в наличии.

Кнопка «Экспорт в CSV» на каждой вкладке — файл скачивается на устройство.
Если закрытых сделок меньше трёх — честная плашка «данных пока мало»:
цифры верные, но выборка крошечная.

## Ещё — разделы, чек-лист и версия

- **Разделы**: Аналитика, Инбокс, Telegram-бот, Поставщики, Позиции
  и остатки, Каналы, Аккаунты, Реквизиты и налог.
- **«Перед запуском»** — чек-лист из 7 пунктов (реквизиты, поставщик,
  позиция, канал, бот в канале, OPENROUTER_API_KEY, R2 — опционально).
  Каждый пункт — кнопка в нужный раздел. Кнопка **«Скопировать
  инструкцию»** копирует пошаговый план запуска в буфер — можно
  отправить помощнику или сохранить в заметки.
- **«Версия и обновления»**: текущая версия и дата, ссылки на
  репозиторий GitHub, README и это руководство.
- **Настройки**: реквизиты, налоговый режим по умолчанию, тёмная тема.
- **Выйти**: уничтожает серверную сессию и чистит данные устройства;
  приватные разделы потребуют входа заново.

Вход — одна пара логин/пароль (задаётся переменными окружения на
сервере). Отдельной регистрации нет: приложение для одного владельца.

## Как работает гео-ротация

Ежедневный постинг в один и тот же канал — спам-сигнал и путь к бану.
Поэтому размещаемся по городам региона: Пн — Ростов, Вт — Таганрог,
Ср — Шахты. Покрытие региона — полное, каждый канал видит объявление
раз в 1–2 недели.

- **Cooldown 3 дня**: каналу, где размещали меньше трёх дней назад,
  подборка даёт бейдж «⏳ N дн» и ставит в конец списка. Считается по
  последней публикации любого объявления — банят за частоту постинга
  автора, а не за товар.
- **«Никогда не размещали»** — лучшая площадка: свежая аудитория, идёт
  первой в подборке.
- **Виджет «Ротация по региону»** в шаге «Каналы» показывает города
  региона, когда в каждом размещали, и рекомендует город на сегодня.
- В ротацию входят каналы с тегом товара ИЛИ «общий»; в строгую подборку —
  только точные совпадения тега.
- Заполните «Город» у каналов одного региона (≥2 городов) — и ротация
  заработает сама.

## Как работает AI (5 сценариев + защита от сбоев)

AI подключён как «тихий ассистент»: он предлагает, вы решаете. Пять
сценариев:

1. **Объявление** («Сгенерировать с AI» в шаге «Текст»): заголовок,
   текст под площадку, теги — лимиты Авито соблюдены.
2. **Ответ покупателю** («Черновик AI» в инбоксе): вежливый ответ
   с ценой и условиями.
3. **«Что сделать?»** на Пульте: приоритетные действия на сегодня.
4. **Проверка цены** (в карточке позиции): позиция дороги/дёшевы
   относительно рынка и что делать.
5. **Логистика** (калькулятор доставки): предварительные оценки ТК,
   которые AI уточняет, а вы отправляете покупателю.

Надёжность: ответ AI валидируется (белый список, лимиты символов,
white-label — имя поставщика не пройдёт проверку ни на входе, ни на
выходе), при сбое — один повтор с усиленным промптом, затем честный
**fallback-шаблон**. Приложение никогда не падает из-за AI: текст
всегда есть, тост честно скажет «AI недоступен, использован шаблон».
Повторные запросы дешевле — кэш на 24 часа.

## Как работает anti-ban

Правила, чтобы аккаунты и каналы жили долго:

- **Автопостинг — только в свои каналы через бота** (где
  @aylatica_sales_bot админ). Чужие чаты и площадки — полуавтомат:
  текст + deep link на точку подачи + отметка «размещено».
- **Гео-ротация** — не спамить в один канал (см. выше).
- **Лимиты аккаунтов**: 20 размещений в день по умолчанию; счётчик
  «использовано сегодня» не даст незаметно превысить.
- **Лимиты каналов**: «frequencyLimit» хранится в карточке канала
  («2 раза в день») — учитывайте при размещении.
- **Документы и переписка — white-label**: поставщик не упоминается,
  покупатель общается только с вами.

## Что делать, если что-то не работает

| Симптом | Что проверить |
|---|---|
| Приложение открывается 30–60 сек | Бесплатный tier Render: api «спит», первый запрос будит. Норма, не перезагружайте страницу |
| «AI недоступен, использован шаблон» | `OPENROUTER_API_KEY` (или `GLM_API_KEY`) в Render env; ответ всё равно есть — шаблон |
| Бот молчит, инбокс пуст | «Ещё» → «Telegram-бот»: webhook установлен? бот админ в канале? напишите боту `/start` |
| Документ не создаётся | Заполнены ли реквизиты (ИНН, адрес, банк, БИК, счёт) в «Ещё» → «Реквизиты» |
| Фото не грузится на позицию | Без R2 — фото до 8 МБ хранятся в базе, видео нельзя; настройте R2 (README → «Как настроить R2») |
| Карусель/данные пустые | Потяните обновление страницы; каталог грузится при открытии Пульта/мастера |
| Сессия истекла | Приложение само перенаправит на страницу входа; логин/пароль — из env (`OWNER_LOGIN`, `OWNER_PASSWORD_HASH`) |
| Нужны данные в Excel | «Аналитика» → «Экспорт в CSV» на каждой вкладке |

Если проблема осталась: раздел «Версия и обновления» в «Ещё» ведёт
в репозиторий GitHub и README — там инструкции по всем настройкам
(R2, ключи AI, деплой). Логи API — в Render → agropost-api → Logs.
