# Этап 2 — Каналы и интеллект размещения (готово)

Дата: 2026-11-24 · Версия: 0.3.0 · Статус: **завершён, задеплоен**

## Что сделано

- **Prisma-модели** `Channel`, `Account`, `Listing` (миграция
  `stage2_channels_accounts_listings`), enum'ы `ChannelType` (7 типов),
  `AccountPlatform`, `AccountStatus`, `ListingStatus`; теги каналов —
  `String[]` со словарём в коде.
- **Seed**: 10 демо-каналов из брифа (Фермеры Кубани, Барахолка Динского
  района, Кормовые травы ЮФО, Copany Market, Фрукты Овощи Оптом, Орех оптом
  РФ, Агросервер, Авито, MAX, Юла) + 2 Telegram-аккаунта (основной 20/день,
  резервный 15/день). Телефоны и URL — заглушки для замены.
- **API**: CRUD каналов с фильтрами (type/tag/region/q), CRUD аккаунтов,
  `POST /api/positions/:id/suggest-channels` (3–5 каналов), листинги:
  `POST` создаёт черновик с шаблонным текстом (сервер, white-label), `PATCH`
  статусы DRAFT→COPIED→PUBLISHED (+`publishedAt` и +1 к `usedToday` аккаунта
  канала со сбросом дня), `GET` по `positionId`, `DELETE`.
- **Экраны (apps/web)**: «Каналы» (фильтры Все/Telegram/Площадки, поиск,
  теги-чипы, карточка + Sheet с Открыть/Скопировать URL/Изменить/Удалить),
  «Аккаунты», мастер «Разместить» в 4 шага (позиция → подбор каналов +
  «Показать все» → черновики под каждый канал с кнопками Скопировать/Открыть
  канал/Отметить размещено → сводка), Пульт: «размещено в N каналов» в ленте.
  Кнопка «Разместить эту позицию» из карточки позиции ведёт сразу к шагу
  каналов.
- **Превью**: те же компоненты `apps/web` (без дублей), мок-API
  каналов/аккаунтов/листингов поверх `shared/seed-data` — контракт 1:1
  с Fastify.
- **shared/**: `channels.ts` (словарь тегов + `rankChannels`),
  `listing-text.ts` (шаблоны текста под площадку — сервер и веб),
  типы/подписи/сид в `types`/`labels`/`seed-data`.

## Архитектурные решения (вопрос → ответ)

| Вопрос | Решение |
|---|---|
| Теги каналов: enum или строки? | Словарь в коде (SEEDS, NUT, LIVESTOCK, WHOLESALE, GENERAL) + zod; в БД `String[]`. Новый тег — правка константы без миграции; парсеру этапа 2.5 легко матчить. |
| Охват: вручную или TGStat? | Вручную (`subscribersCount`, `averageReach`, `lastActivityAt`). TGStat платный и не покрывает Авито/Агросервер/MAX/Юлу; добавить можно в 2.5 без смены схемы. |
| Мультиаккаунты: таблица или сессии? | Учётная таблица (платформа, телефон, статус, `dailyLimit`, `usedToday` с автосбросом дня). Сессии Telethon/cookies — этап 3, когда появится автопостинг. |

## Проверки

- **API-чеклист: 30/30 PASS** (CRUD каналов и аккаунтов, фильтры
  type/tag/region/q, валидация URL и тегов, подбор для семян и орехов,
  листинги DRAFT→COPIED→PUBLISHED, `publishedAt`, счётчик аккаунта,
  white-label: регион в тексте есть / имени поставщика нет, 409 на удаление
  канала с размещениями, meta stage=2).
- **Браузер (превью): 10/10** — добавить канал → отфильтровать
  (Telegram+поиск) → Аккаунты → разместить «Люцерну Вега 87» в 2 канала →
  черновики white-label → «Размещено» → сводка → лента Пульта
  «размещено в 2 канала».
- **Сборка apps/web**: `tsc --noEmit` + `vite build` — 0 ошибок
  (1622 модуля, PWA-прекеш собран).

## Правила, которые соблюдаются

- **White-label**: черновик собирает сервер (`shared/listing-text.ts`);
  имя поставщика не упоминается — только регион отгрузки. Проверено
  API-тестом и браузером.
- **Анти-бан**: автопостинга нет (этап 3), всё полуавтоматическое —
  текст + deep link + отметка.

## Ограничения (не блокеры)

- R2 не настроен — медиа отдают 503 (нужно до этапа 3, там фото в объявлениях).
- Neon free-tier засыпает: первый запрос ~30 сек.
- Репо публичное (как в этапе 1); закрыть можно после этапа 2 через
  private + Render Repository Access.
- Телефоны/URL демо-каналов — заглушки, заменить в интерфейсе.
