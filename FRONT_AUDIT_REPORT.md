## 6. Что осталось доделать (честный список)

1. **Парсер цен** (services/parser) не задеплоен — «Цены рынка» показывает «парсер цен не настроен». Разворачивается опционально по README (Render-сервис закомментирован в render.yaml); без него приложение полноценное, кроме автоцен.
2. **Ключи Авито/MAX** не заданы — «Авто»-публикация недоступна, полуавтоматическая работает; фиды готовы.
3. **Userbot** требует отдельного запуска на VPS (TELEGRAM_SESSION) — инструкция в README.
4. **R2** не настроен — фото хранятся в базе (base64), для объёмных медиа подключить по README.
5. **Скорость AI**: бесплатные модели OpenRouter отвечают 4–35 сек и состав free-тира меняется. Каскад правится без кода — env `OPENROUTER_MODELS` на Render; для стабильно быстрых ответов можно пополнить кредиты OpenRouter и добавить платную модель в конец списка (сейчас платные модели с этого ключа дают 403 — регион-гейт).
6. **Реквизиты пользователя** не заполнены (чек-лист 4/7) — без них не сформируются счёт/договор/УПД.
