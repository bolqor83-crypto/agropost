Дата: 24.11.2026 · Версия API: 0.4.0 · Коммит: `f422036` · Прод жив:

## Что сделано (по частям ТЗ)

### Часть A — обогащение модели каналов

- **Prisma** (`apps/server/src/prisma/schema.prisma`), аддитивно (`prisma db push`
  на Neon, существующие записи не тронуты):
  - `Channel`: `submissionMethod` (enum BOT/ADMIN_CONTACT/SITE_FORM/CABINET/NONE,
    default NONE), `submissionBotUsername`, `adminContact`, `frequencyLimit`,
    `confirmationStatus` (CONFIRMED/REQUIRES_CHECK, default CONFIRMED),
    `mirrorOf` — self-FK с обратной связью `mirror/mirroredBy` (TG↔MAX),
    `audienceType` (B2B/B2C/REGIONAL/GENERAL, nullable).
  - `CompetitorPrice` (часть B): source, query, price, unit, region, sellerName,
    link, rawSnippet, fetchedAt; индексы по source, query, fetchedAt и составной.
- **Сид**: 14 демо-каналов этапов 2/2.1 **удалены** (только фиксированные
  демо-идентификаторы — пользовательские каналы не тронуты), вместо них —
  **20 реальных из исследования** (`docs/CHANNEL_RESEARCH.md`, создан из ТЗ).
  reach из исследования → `subscribersCount` (охват не измеряли — честный null);
  лимиты подач исследование не зафиксировало — null.
- **API**: `POST/PATCH /api/channels` принимают новые поля (зеркало проверяется:
  несуществующее → 404, на себя → 400); `GET /api/channels(:id)` возвращает;
  `suggest-channels` отдаёт полные DTO с полями подачи.
- **UI (apps/web)**:
  - шит канала (просмотр): Способ подачи («бот-приёмщик @Taganrog_Predlozhka_bot»),
    Лимит подач, Статус проверки, Аудитория, Зеркало (по имени);
  - форма канала: селекты способа/статуса/аудитории + поля бота/админа/лимита;
  - каталог: жёлтый бейдж «требует проверки» (REQUIRES_CHECK) и строка
    «Подача: …» на каждой карточке;
  - мастер «Разместить», шаг 3: кнопка ведёт в правильную точку входа —
    «Открыть @Taganrog_Predlozhka_bot» (deep link `https://t.me/…`),
    «Написать @Ivan_plants12» (deep link), SITE_FORM/CABINET → «Открыть
    страницу подачи» (Channel.url); логика общая — `shared/channels.ts`
    (`submissionTarget`), для MAX-каналов deep link строится к самому каналу
    (у MAX-ботов свой формат ссылок).

### Часть B — парсер цен

- **Архитектура** (выбор пользователя): отдельный Python-сервис
  `services/parser` — FastAPI + httpx + Telethon + APScheduler + asyncpg;
  Node-бэкенд только проксирует запуск (`PARSER_URL`, дефолт 127.0.0.1:8000).
- **Агросервер — sitemap-подход** (robots.txt запрещает `/search/` — им не
  пользуемся): читаем официальный `sitemap.xml` (инвентарь для роботов),
  объявления `/b/*.htm` отбираем по транслит-ключевым словам («люцерна» →
  lyutserna, «суданка» → sudan), цену извлекаем из **текста** страницы
  (регексп «180 ₽/кг» — смены вёрстки не ломают). Лимит 1 запрос / 2 сек,
  User-Agent браузера. Разведка 24.11.2026: объявления лежат в ПЕРВЫХ чанках
  sitemap (хвостовые — категории), адаптер читает первые N
  (`AGROSERVER_SITEMAP_CHUNKS`, для первого полного наполнения истории
  поставьте 30).
- **Telegram**: Telethon (MTProto), **отдельный аккаунт** (креды
  TG_API_ID/TG_API_HASH/TG_SESSION в `.env`, получение сессии —
  `python -m app.login`), только публичные каналы из TG_CHANNELS, лимит
  1–2 запроса/сек, пауза при FloodWait, максимум 500 каналов. Кредов пока
  нет → честный статус `skipped`, Агросервер работает дальше (выбор
  пользователя).
- **152-ФЗ**: сниппеты чистятся на лету — телефоны, e-mail, URL вырезаются
  (`app/extract.py`), sellerName для TG не заполняем (имена отправителей =
  ФИО). В прод-сид демо-цены НЕ пишутся: превью показывает строку «Рынок»
  на демо-данных (помечены «Демо»), прод увидит реальные цены после первого
  прогона парсера.
- **API (Node)**: `GET /api/positions/:id/market` — агрегаты по культуре
  (min/max/avg, sources, последние 5 сэмплов, окно 30 дней через
  `shared/market.ts`), кэш 24 ч («обновление раз в день»), пустой результат
  не кэшируется; `POST /api/parser/run` (валидированное тело queries/sources,
  инвалидация кэша после успешного запуска), `GET /api/parser/status`.
  Парсер недоступен → 503 PARSER_UNAVAILABLE с человекопонятным сообщением,
  приложение живёт.
- **UI**: строка «Рынок: 160–240 ₽ / кг · средняя … · N цен · Агросервер +
  Telegram» в экономике карточки позиции; без данных — «данных пока нет».
- **Cron**: APScheduler внутри сервиса, раз в 12 ч
  (`SCHEDULER_INTERVAL_HOURS`), ошибки прогона не убивают расписание.
- **Деплой парсера**: пока локально (по ТЗ «можно локально»); Dockerfile
  готов, в `render.yaml` добавлена закомментированная запись сервиса
  (раскомментировать, когда решите поднять на Render).

## Ключевые решения и отклонения

1. **Выборы пользователя (по вопросам перед кодом)**: Python-сервис вместо
   Node-модуля; отдельная таблица CompetitorPrice вместо JSONB; TG-кредов
   пока нет — Telethon-адаптер с graceful-skip.
2. **`(БАРАХОЛКА) Ростов–Таганрог`** (№14 исследования): username не
   зафиксирован (запись «открыть» из каталога) — канал оставлен со статусом
   REQUIRES_CHECK и ссылкой-заглушкой; заметка на карточке просит проверить
   и заменить. То же для «Новочеркасск аграрный» (заглушка из 2.1).
3. **MAX-боты** (№15, №18 @DaromTagBot): deep link t.me не строим — у MAX
   свой формат; кнопка открывает сам канал, имя бота видно в подписи.
4. **Демо-история ротации** пересеяна: Новочеркасск «размещали» 2 дня назад
   (cooldown) → recommendedCity = Таганрог. Шахты/Ростов-на-Дону каналов в
   новом исследовании нет — ротация из городов Таганрог + Новочеркасск.
5. **Sitemap-разведка** (24.11.2026): хвостовые чанки sitemap содержат
   только страницы категорий (0 объявлений /b/) — поэтому адаптер берет
   ПЕРВЫЕ чанки, где лежат объявления. IP песочницы Агросервер закрыл
   капчей: живой прогон показал robots ✓, sitemap ✓, подбор кандидатов ✓
   (реальное объявление люцерны найдено), страница объявления — капча →
   статус `blocked`, 0 записей, сервис не упал. С машины пользователя /
   Render сбор пройдёт (ТЗ: «ручной запуск, если IP блокируется»).
6. **Превью**: добавлена защита версии кэша мок-БД (globalThis) — hot-reload
   не оставляет старую форму данных после смены схемы.

## Как запустить парсер (пользователю)

```bash
cd services/parser
cp .env.example .env       # DATABASE_URL (Neon); TG_API_* — когда будут
pip install -r requirements.txt
python -m pytest          # 29 тестов
uvicorn app.main:app --port 8000
curl -X POST http://127.0.0.1:8000/run -H 'Content-Type: application/json' -d '{}'
# или через приложение: POST https://agropost-api.onrender.com/api/parser/run
```

После первого прогона строка «Рынок» в карточках позиций оживёт на проде.
Для полного первичного наполнения: `AGROSERVER_SITEMAP_CHUNKS=30`.
