## Часть B — валидация атрибутов против AI-галлюцинаций

1. **displayType в attributesSchema** (`shared/types.ts`, `AttributeField.displayType`):
   `FIXED` (точное значение) / `RANGE` («45–50», «32+») / `MIN` («не менее 45») /
   `TEXT` (свободный текст). Поле опционально; по умолчанию — TEXT для text-полей,
   FIXED для числовых. Zod-схема `attributeFieldSchema` принимает displayType при
   создании/правке культур. Prisma-схема не менялась (JSONB), комментарий обновлён.
2. **`validateAttributes(schema, values)`** (`shared/attributes.ts`): возвращает список
   нарушений формата — FIXED-число в границах типа, RANGE «45–50»/«32+» (min ≤ max),
   MIN — минимум (не диапазон), TEXT — строка. Текстовое поле может нести числовой
   контракт (калибр «32+» = type text + RANGE). `normalizeAttributes` теперь
   канонизирует диапазоны («45 - 50» → «45–50», «32 +» → «32+») и не пускает мусор.
3. **Жёсткое правило в промпте `listing.md`** (пункт 6 ТРЕБОВАНИЙ): для FIXED/RANGE/MIN —
   использовать ТОЛЬКО переданное значение; генерировать, округлять и изменять числа
   запрещено; значения нет — характеристика не упоминается. В факты позиции
   (`positionFacts`) к каждому атрибуту добавлена подсказка формата.
4. **Пост-проверка чисел в `gateway.ts`**: `extractNumbers(text)` + `hallucinatedNumbers` —
   из ответа извлекаются все числа (включая границы диапазонов и «10 000» с пробелом),
   каждое обязано быть в `allowedNumbers` (атрибуты позиции + цена, объём, фасовка,
   мин. партия + детерминированные производные: мешки, тонны, выручка, цена за тонну).
   Чужое число → ответ отклонён → retry 1 (усиленный промпт: «числа только из входа») →
   fallback на шаблон. Подключено к use cases **listing** и **reply**.

## Часть D — OpenRouter как резерв

1. `openrouter.ts`: baseURL `https://openrouter.ai/api/v1` (подтверждено тестом).
2. Каскад моделей: `OPENROUTER_MODELS` (через запятую) или по умолчанию
   бесплатные — `deepseek/deepseek-v4-flash-0731:free`, `qwen/qwen3.8-27b:free`,
   `google/gemma-4-26b-a4b-it:free`, `nvidia/nemotron-3-ultra-550b-a55b:free`
   (если задан OPENROUTER_MODEL — платная модель идёт первой).
3. `complete()` обходит список, пока модель не ответит (HTTP/сеть/пустой content
   → следующая); после успеха курсор смещается — ответ на retry начинается со
   следующей модели. Все упали → `AiProviderError` → gateway fallback. Сценарий
   «GLM недоступен (нет ключа/сбой) → OpenRouter» уже существовал, теперь внутри
   OpenRouter их 4–5 моделей каскадом. `.env.example` дополнен `OPENROUTER_MODELS`.

## Ограничения / что осталось

- `allowedNumbers` охватывает детерминированные производные цены/объёма (мешки,
  тонны, выручка, цена за тонну). Число вне входа И вне производных → fallback:
  возможно, часть «умных» перефразирований (например, «около 10 тонн» при 9 750 кг)
  уйдёт в шаблон — это осознанная цена жёсткости.
- Числовой пост-чек включён для listing и reply (текстов про позицию); для
  advice/price_analysis/logistics выходы считаются на сервере — там галлюцинация
  чисел исключена дизайном.
- R2 не настроен (медиа 503) — PDF хранятся base64, фото рекламаций — этап R2.
- Гипотеза о «9%»: число НЕ из входа. С патчем такое отклоняется до показа
  пользователю; AiCall-журнал фиксирует статус и текст ошибки.
