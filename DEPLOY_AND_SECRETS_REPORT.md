## 3. Управление секретами (новое, «Ещё» → «Настройки»)

- **Где**: «Фиды» (FEED_TOKEN), «Telegram-бот» (TELEGRAM_BOT_TOKEN, TELEGRAM_USER_ID), «AI (OpenRouter)» (OPENROUTER_API_KEY) — на хабе настроек; Авито и MAX — в своих экранах (как в этапах 9–10).
- **Шифрование**: AES-256-GCM, в AppSetting (PostgreSQL) — только шифротекст `v1:iv:tag:ct`; ключ `SECRETS_ENCRYPTION_KEY` (задан на Render). В дампе БД секретов нет.
- **Клиент видит только маски** `••••1234` и флаги «настроено/через env/не настроено» — сырые значения из API не отдаются (в т.ч. авито-ключи теперь маскируются).
- **env платформы приоритетнее**: такое поле в UI только для чтения, PUT → 400.
- **«Проверить подключение»** — реальные запросы: Авито OAuth `POST /token`, MAX `GET /me`, OpenRouter `GET /api/v1/auth/key`, Telegram `getMe`, фиды — запрос к собственному фиду по токену.
- **Когда вступает в силу**: фиды и Авито — сразу; MAX-публикация — сразу (приём сообщений — после перезапуска); OpenRouter и Telegram — после перезапуска API (подсказка на экране).
- **Аудит**: таблица AuditLog (миграция `20261126120000`) — кто, когда, какое поле, маски «было → стало»; последние изменения — «История переменных» на экране настроек. Без SECRETS_ENCRYPTION_KEY — честный баннер и 503 на сохранение (env работает).

## 5. Деплой: как сделан

1. Env дополнены через Render API (PUT с мержем — существующие переменные сохранены, проверено повторным GET).
2. `POST /v1/services/{id}/deploys` с `clearCache: "clear"` для api и web; поллинг до live.
3. Первая сборка api упала: `src/settings/__tests__` не был в exclude tsconfig — на Render (без песочницы) `bun:test` не резолвился; локально маскировалось чужим node_modules выше по дереву. Фикс `1f0d79c` (проверен в npm-зеркале сборки), повторный деплой — live.
4. После деплоя проверены: meta (1.1.0/stage 10), health, /api/max/status (200, не 500 → миграции есть), вход, фиды 200/403, 9/9 записей в `_prisma_migrations`.

## 6. Что делать пользователю

1. **Войти**: https://agropost-web.onrender.com — логин `agropost`, пароль из сообщения в чате. Пароль можно сменить: `cd apps/server && bun run hash-password` → новый хеш в `OWNER_PASSWORD_HASH` на Render.
2. **Настроить Авито/MAX** — «Ещё» → «Настройки» → «Авито API» / «MAX»: ключи сохраняются зашифрованными, «Проверить подключение» покажет, работают ли они.
3. **Фиды** — «Настройки» → «Фиды»: скопировать YML-ссылку в кабинеты Зерно Он-Лайн / Своё Фермерство.
4. **Userbot** — отдельно на своей машине/VPS (services/userbot, README «Как настроить userbot»): только чтение, отправки нет.
